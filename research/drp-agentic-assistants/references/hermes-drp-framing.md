hermes-drp-framing.md

This reference contains a concise mapping used when drafting the paper and slides:

- "Artifact produced" => where it's saved: path, git commit, DOI, S3 URL
- "Skill identity" => skill name + semantic version + changelog entry
- "CI evidence" => CI job id / logs URL / test reports

Include these three items in any assistant-generated patch or publication manifest to make Hermes contributions auditable.
