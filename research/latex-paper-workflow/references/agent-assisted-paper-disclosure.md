# Agent-assisted paper disclosure pattern

Use this when the user wants the manuscript itself to say it was written with an agentic writing system.

## Durable pattern

Keep the disclosure synchronized across artifacts:
- paper title page / author block
- body text (short methods-style paragraph or section)
- acknowledgements
- slide deck title page or one dedicated slide

## Recommended wording pattern

Prefer controlled wording:
- "written/developed using <system> as a structured writing and review scaffold"
- "literature-search, novelty-generation, adversarial review, and style-tightening passes"
- "final source selection, framing, and claims were manually curated"

Avoid stronger wording unless the user explicitly wants it:
- "the agent wrote the paper"
- "the system established correctness"
- "fully automated scientific writing"

## Session-derived example

A useful concrete formulation is:

"The workflow combines six novelty engines, ten adversarial reviewer personas, and one academic humanizer as a portable 17-skill writing stack. In this draft, that stack was used to generate angles, pressure-test claims, and tighten style, after which final source selection and framing were manually curated."

## Why this belongs in the paper

For papers about reproducibility, agentic systems, workflow infrastructure, or scientific tooling, the writing pipeline is part of the methods context. A short disclosure improves auditability and prevents the contribution from sounding detached from the actual production process.
