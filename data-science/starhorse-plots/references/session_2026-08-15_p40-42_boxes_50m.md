## 50M full-suite runs
- Host: 121 GB RAM. Working 50M run: `PYTHONPATH=src python -m sh26 plots --all --no-cuts --data data/sh26_joined_50m.parq --threads 16 --memory 64GB` → 42 ok / 0 failed / ~14 min.
- **NEVER pass `--memory 4GB` on 50M data** (that flag is for the 5M sample): workers get 2 GB each, every parquet read OOM-restarts the workers, and the CLI process appears "running" but hangs indefinitely (futex wait, 0 CPU, no figures written). Symptom checklist: process alive + no `Dask read` lines + `ps` shows no workers.
- Materializing 50M × 2 cols via Dask→pandas is the slow part (~8–14 min); the plot itself is seconds. Launch single-plot 50M renders as background jobs and poll the logfile.
