## Pitfalls (hit while forcing the fixed CMD range)

- **`extent` requires ymax > ymin** → `ValueError` with an inverted y
  pair (15, −6). Use `set_xlim`/`set_ylim` (reversed args allowed).
- **`extent` does not bound the axes** — a later-drawn auto-scaled
  artist (the red selection scatter) re-expands the window. Set limits
  AFTER the scatter, don't rely on `extent`.
- **"the middle plot" is ambiguous** between P90/P91 (both 3-panel with
  a CMD middle). Verify with `grep -n invert src/sh26/plots/pNN_*.py`
  which file each correction belongs to before and after editing.
