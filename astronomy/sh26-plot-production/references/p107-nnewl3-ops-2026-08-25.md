## <compute-node> long-job launch (the big one)

- **Use tmux, not user-systemd.** <compute-node> `Linger=no` → `systemctl --user`
  units are killed when the SSH session closes (observed: ruwe2 build
  SIGTERM'd ~30 s after launch, 0 parts written). <compute-node> systemd is also
  too old for `systemd-run --user --output=`. The agent-host
  `systemctl --user oneshot` pattern (references/host-long-jobs.md) does
  NOT transfer.
- Launcher that works:
  ```
  tmux new-session -d -s <job> -c <dir> \
    "HOME=/tmp PYTHONDONTWRITEBYTECODE=1 <conda-python> <script> 2>&1 | \
     tee <log>; echo EXIT_CODE=$? >> <log>"
  ```
  Reboot WIPES <compute-node> `/tmp` — redeploy scripts after a reboot (md5-verify).
- **Nested double-SSH (agent → Newton 141.33.4.144 → <compute-node>.nnew) steals
  the inner ssh's stdin.** `ssh N "ssh NN 'cat > f'" < local` writes an
  EMPTY file and the outer command hangs to the tool timeout. Working:
  (a) stage on Newton `cat f | ssh N "cat > /tmp/f"`, then
  `ssh N "ssh NN 'cat > f' < /tmp/f"` (in-band redirect, no pipe into the
  outer ssh); (b) if that also hangs, base64-inline
  `ssh N "ssh NN 'echo $B64 | base64 -d > f && md5sum f'"`. Plain `scp`
  to these hosts hangs too — always `cat | ssh`.
- Isolated job dir convention: `/lustre/<user>/tmp/<job>/{src,log}` —
  never touch `/lustre/<user>/hermes/SH26` (live user data). Package
  current `src/` via `git archive`/`tar cf - src | ssh ... > tar`.

## P107 dashboard (full-vs-cleaned, v250826)

Module `src/sh26/plots/p107_full_vs_cleaned_dashboard.py`,
`quality_cuts=False` (the full-vs-cleaned contrast IS the signal — the
global ruwe<=1.4 cut would delete the cleaned rows). 3×4, figsize 26×19:
- Row 1: Mollweide FRACTION maps (bincount(weights)/bincount, min_n=50):
  ruwe>1.4 [full/cleaned], ruwe2=1 [full/cleaned] (Reds, vmin0 vmax1).
- Row 2: Red-Clump Mollweide DENSITY (magma, LogNorm) [full/cleaned] +
  XY & XZ dual hexbin (full Greys a0.55 + cleaned viridis a0.95,
  extent ±50 kpc).
- Row 3: CMD + Kiel dual hexbin, cleaned-fraction Mollweide (Blues),
  RUWE histogram (full grey + cleaned blue, vline at 1.4).

Definitions:
- full = converged (MISSING==False) — applied by the LOADER, not make().
- cleaned (astrometry_clean tier) = `SH_OUTFLAG=="0000"` & `ruwe<=1.4` &
  `plx > 10*plx_err`.
- RC (Friedrich) = 4500<teff50<5000, -0.6<met50<0.4, 2.35<logg50<2.55.
- `SH_OUTFLAG` and `ruwe2` are REAL columns in v250826 (134 cols) — read
  them directly, no per-row recompute.

make() gotchas hit (see SKILL.md pitfalls):
- frame already converged + `MISSING` dropped → KeyError if referenced.
- LogNorm `vmax` must be computed BEFORE `masked_where`; all-empty RC
  panel → title+"(empty)" + skip (fixtures have ~300 RC, real has 9.3M).

Full render: read 402M 16 cols in 19–89 s, converged 327,477,457,
make() 349 s, total 507 s (~8.5 min), ~15 GB peak. n_full=327.5M,
n_cleaned=62,115,761 (19.0%), rc_full=9,346,217, rc_cleaned=2,103,369.

## Vision-down QA (4 vision_analyze timeouts this session)

When vision keeps timing out, deterministic per-panel check:
- FigureCanvasAgg render; crop each DATA axes at pixel bbox
  (`ax.get_position()` × canvas W/H); SKIP axes with a QuadMesh child
  (those are colorbars — they ALSO hold the pcolormesh, so the
  save()-skip-QuadMesh rule does NOT let you identify data axes that way).
- Classify: colored data = (max−min channel > 45) & (not near-white);
  grey mask = #d9d9d9 (low saturation); black = ellipse/borders.
- Per-panel colored fraction > ~0.005 = populated.
- CAVEAT: equal-width figure-thirds do NOT align to axes (hspace +
  colorbars shrink rows) — a row/col grid crop misattributes ink. Use the
  per-axes bbox crop, or just trust the sidecar n_points + counts and
  note vision was down.
